# ADR-0013: 部署——自建云服务器 + Docker Compose，Nginx 反代 HTTPS

## 状态
已接受

## 背景
ADR-0003 定了自建后端（NestJS + MySQL + COS）。部署目标未定；微信小程序硬性要求
request 合法域名必须为 **HTTPS 且域名已备案**，国内服务器对备案有硬约束。

## 决策
- 部署到**自己的云服务器**（如腾讯云轻量/云服务器），用 **Docker Compose** 一栈编排：
  NestJS 后端 + MySQL + Nginx 反向代理，Nginx 终止 TLS（Certbot 续期证书），
  静态资源/前端后续可同机托管。
- 域名走备案流程，小程序的 request 合法域名配置为备案后的 HTTPS 域名。
- 服务器与 COS 同区，降低媒体读写延迟。

## 后果
- 一栈式编排便于迁移/备份/回滚；MySQL 数据卷需单独持久化与备份策略。
- 备案周期长（数天~数周），需**尽早启动**，不阻塞本地开发。
- 无 k8s/多实例需求（MVP 单实例），规模上来后再拆分。
