# ADR-0016: 内容说明支持 Markdown —— 轻量自研渲染，无第三方依赖

## 状态
已接受

## 背景
发布页优化要求内容输入框支持 Markdown 模式，且所有作品类型（text/image/audio_video/
tech/external）都可编辑「内容说明」（文字类型即正文，其余记录介绍/心得）。候选：
引入成熟 Markdown 库（如 marked + html 渲染）或轻量自研渲染。小程序环境无 DOM，成熟
库多按浏览器设计，需要适配层；需求只覆盖常用排版语法。

## 决策
- **轻量自研渲染**：前端 `components/Markdown.tsx` 实现解析器，支持标题（h1-h6）、
  加粗、斜体、行内代码、代码块、无序/有序列表、引用、链接、图片；不引入任何新依赖。
- **双处共用**：发布页「预览」与详情页正文/说明渲染同一个组件，风格一致。
- **安全**：不引入 HTML 注入面——块/行内解析直接产出 Taro 节点，文本经 React 转义。
- **链接交互**：小程序无内置浏览器，链接点击复制到剪贴板。
- **编辑体验**：说明区「编辑 / 预览」切换；文本超长上限放宽到 20000（配合 text_content）。

## 后果
- 无第三方 Markdown 依赖，包体积与升级负担为零；语法覆盖常用子集。
- 未来若需要表格/任务列表/脚注等扩展语法，或需要严格 CommonMark 语义，再评估
  替换为成熟库（届时仍是单点替换，组件接口不变）。
- 解析器为自定义实现，语法兼容性以本 ADR 列出子集为边界。
