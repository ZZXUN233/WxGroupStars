# ADR-0005: 文件类作品媒体存储用腾讯云 COS

## 状态
已接受

## 背景
作品包含图片、音视频、文件等媒体内容（文字/图片/音视频/技术/外部五种类型）。
媒体不能存数据库过大的字段，需要对象存储。项目为微信小程序 + 自建 Node 后端。

## 决策
- 文件类作品的媒体内容上传到**腾讯云 COS（对象存储）**。
- 数据库（MySQL）仅存 COS 的**对象 key / URL**，不存二进制。
- 上传流程：后端签发 STS/临时密钥（或预签名）→ 前端直传 COS → 后端记录元数据；
  避免媒体流量经过自建后端，降低带宽与延迟。

## 后果
- 存储、CDN、带宽交给 COS，自建后端只管业务逻辑与元数据。
- 需要处理 COS 的鉴权（STS 临时密钥）与 CORS/防盗链配置。
- 媒体 URL 长期有效策略、清理（撤销/删除作品时媒体是否删除）需另行决策。

## 补充：媒体数量模型（配合 ADR-0009）
- **图片作品可含多张**（1–9 张），`work.media_url` 存 COS object key 的**数组 JSON**。
- **音视频作品为单文件**，`media_url` 存单个 object key。
- **封面必填**：时间轴与分享卡片均需封面；作者未单独上传封面时，默认取第一张图片。
- 文字/技术/外部类型无媒体，走各自的正文字段。
