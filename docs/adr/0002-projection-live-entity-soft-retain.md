# ADR-0002: 投影是可追加/可撤销的活实体，互动数据软保留

## 状态
已接受

## 背景
投影常被当成"发布时一次性创建的软链接"。但产品需要把投影与"可见性授权"绑定，
并允许作者事后调整作品的可见范围。

## 决策
- 投影是**活实体**：作者可随时**追加**（把作品投影到新群，即授权该群可见）、
  **撤销**（收回某群可见性）。追加与撤销共享同一入口。
- **仅作者本人**可追加/撤销投影。群主/管理员无治理权（本版本）。
- 撤销投影时，该投影上的点赞/评论/收藏**软保留**：隐藏不可见但保留在库中；
  若作者将来重新投影回该群，互动数据**复活**。

## 后果
- 撤销是对"可见性"的动作，不是对"数据"的销毁，不永久抹掉真实群体反馈。
- 需要为投影与互动记录引入"软删除/状态"字段（如 `is_active` / `deleted_at`），
  而非物理删除投影。
- 数据模型上投影是显式实体（非作品字段内的一个数组），可单独增删、独立持有互动。
