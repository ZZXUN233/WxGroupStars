# ADR-0009: 作品本体可编辑、可软删（隐藏全部投影），媒体随之保留

## 状态
已接受

## 背景
PRD 未定义作品发布后的生命周期；ADR-0002 只授权作者追加/撤销投影（改可见性），
未覆盖作品本体的编辑与删除。需要定义：作者能否改已发布作品，删除是否物理销毁。

## 决策
- **可编辑**：作者可修改标题、正文/媒体、封面、类型、标签。因投影是对本体的软链接，
  修改立即反映到该作品的所有投影与群内展示。
- **可软删**：删除作品 = 作品 `is_active=0`，**隐藏其全部投影**与互动，数据保留。
- **无硬删（MVP）**：不提供物理删除入口；COS 媒体随作品保留，不清理。
  （ADR-0005 遗留的"媒体何时清理"由此收敛为：无硬删，媒体随软删保留。）

## 后果
- work 表需增加 `is_active`、`updated_at` 字段；删除/编辑均为写操作而非读操作。
- 撤销单个投影（ADR-0002）与删除整个作品是两个层级：前者隐藏本群投影，
  后者隐藏全部投影。
- 媒体生命周期与作品一致（软删不删），避免误删后无法恢复；未来若引入硬删/合规
  清理，需另行决策。
