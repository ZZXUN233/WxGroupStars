# ADR-0010: 跨群聚合视图按成员资格过滤——星轨/最新星光/搜索/收藏只显示共同群内容

## 状态
已接受

## 背景
ADR-0006 确立了"群空间完全封闭、非成员不可见"的读接口基准。但产品存在天然的
**跨群聚合视图**：作者星轨（作品数量/分类分布/最近作品）、首页最新星光、跨群搜索、
个人收藏列表。若不限定口径，这些视图会把非成员群的作品泄露出去，破坏封闭性。

## 决策
- 所有跨群聚合视图一律**按查看者的成员资格过滤**：
  - **星轨**：只统计并展示"查看者已加入的群空间"里该作者的投影；与查看者无共同群
    时星轨为空。从某群点进作者时，优先以该群作为展示上下文（用该投影的互动计数）。
  - **最新星光 / 我的收藏**：只返回"查看者已加入的群空间"内的投影。
  - **搜索**：MVP 为**群内作用域**——进入某群后先选定该群空间，只搜该群投影
    （标题/内容/作者/标签）；MVP 不做跨群全局搜索。
- 统计口径（数量、分类分布、热度）只数可见的投影，不数被过滤掉的。

## 后果
- 封闭性基准从"单接口校验"统一为"所有读取按成员资格投影到可见集"，口径一致、
  无外泄。
- 每个聚合查询都带一遍 membership 过滤（与 ADR-0006 的成员校验同成本，可索引/缓存）。
- "作品被转发到非投影群天然不可见"的规则（ADR-0006）在所有聚合视图上同样成立。
