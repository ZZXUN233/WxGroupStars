# ADR-0003: 技术栈——Node.js (TS) 自建后端 + Taro 前端 + MySQL，不采用微信云开发

## 状态
已接受

## 背景
[决策前] 在考虑后端与前端技术栈时，候选有微信云开发、自建后端、云函数+外部库等。

## 决策
- **前端**：**Taro 框架**（React 语法，编译到微信小程序）。
- **后端**：**Node.js (TypeScript)** 自建后端，框架为 **NestJS**（依赖注入/模块化/装饰器，
  配套 CLI 脚手架）。
- **数据库**：**MySQL**（团队偏好；规范化数据模型足够支撑）。
- 不采用微信云开发：不锁定微信云，保留跨平台与自托管自由度。

## 后果
- 需自建微信登录鉴权链路（code2session 取 openid/session_key）与会话管理。
- 前后端同用 TypeScript，类型共享便利。
- 前端分享/登录依赖微信小程序原生能力；若未来多端编译，H5 端需另写降级实现。
- 数据访问与管理完全掌控在自建后端，脱离微信云数据库的安全规则体系。
