# ADR-0006: 群空间完全封闭，非成员不可见（访问控制基准）

## 状态
已接受

## 背景
产品为"基于微信群关系的封闭作品社区"。作品通过"投影"进入某群空间，
可见性受"成员资格"双重约束：作者须是群成员才能投，读者须是投影群成员才能看。

## 决策
- 群空间**完全封闭**：所有群内作品仅**该群成员**可见。
- 非成员点开分享链接/作品，看到"加入群后方可查看"，不返回内容。
- 后端在每个"读取投影/作品"的接口上，**实时以 member 表校验**：请求者 `user.id`
  是否在投影对应 `space` 的成员表中；不通过则拒绝。
- 首页"我的群"只列用户已加入的群空间。

## 后果
- 安全边界明确，数据不外泄；但**分享传播的"引流可见"价值被放弃**
  （非成员看不到内容，是否需要诱饵预览后续可讨论）。
- 所有读接口需做成员校验，增加一遍 membership 查询（可加索引/缓存缓解）。
- "作品被转发到非投影群"天然被拦截，符合"转发也不可见"的规则。

## 补充：微信分享卡片与封闭性的权衡
- 微信分享卡片（标题+封面）由微信客户端渲染，**非成员在聊天窗口也能看到**，
  后端无法拦截卡片本身。
- 决策：对**非群成员**的分享卡片展示**中性「群星闪耀」标题与通用封面**，
  不暴露具体作品名/作者，贯彻"完全封闭"；点进小程序后再做成员校验拦截。
- 代价：牺牲 PRD 中"精美作品卡片引流"的价值（分享打开率下降）。
  （需在小程序端通过登录态判断读取者是否成员，动态决定生成的卡片内容。）
