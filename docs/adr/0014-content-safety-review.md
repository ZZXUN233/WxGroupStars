# ADR-0014: 内容安全审核——MVP 即接入微信文本 + 图片审核

## 状态
已接受

## 背景
作品社区是典型 UGC，微信小程序上架要求接入内容安全能力：文本 `msgSecCheck`（同步）、
图片/音视频 `mediaCheckAsync`（异步回调）。本产品核心内容形态是图片，审核缺失有
拒审/下架风险。

## 决策
- **MVP 即接入**：发布/评论时**文本同步**过 `msgSecCheck`，违规直接拦截提交；
  **图片上传后异步**走 `mediaCheckAsync`，回调违规则**隐藏**该作品。
- 审核期间策略：图片审核结果返回前**先展示**（乐观），回调违规即隐藏；
  若上架要求更严，可改为"审核通过前不展示"。
- 违规处理：**隐藏而非删除**，保留数据与申诉空间；计数/互动随隐藏不展示。
- 音视频量小，MVP 仅做文本+图片；音视频复用 `mediaCheckAsync` 留待 V2。

## 后果
- 需配置微信内容安全**回调地址**；图片审核为异步，work 表需落"审核状态"字段
  （`review_status`）。
- 每次发布/评论多一次外部调用（受微信频控），需限流与失败降级策略
  （审核服务不可用时允许发布但不保证合规，或拒绝——按上架要求收紧）。
