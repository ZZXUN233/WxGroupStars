01

产品概述

产品背景

微信群已经成为人与人之间交流的重要场景，大量用户会在群中分享原创内容：

原创文章摄影作品绘画作品 音乐作品技术项目思考观点 创意作品

但微信群的信息流模式存在天然缺陷

内容被淹没

好内容快速被新消息刷走

难以再找到

优秀作品无法回溯检索

缺少展示空间

创作者没有长期主页

创造力无法沉淀

群体记忆随时间流失

解决方案

构建一个「属于微信群成员自己的作品社区」，让每一个群成员的创造，都成为群体记忆的一部分。
02

产品定位

《群星闪耀》是一款基于微信群关系的作品沉淀社区，让微信群中的每一次创作，都拥有长期保存、展示和交流的空间。

微信负责

关系 · 传播 · 互动

群星闪耀负责

记录 · 整理 · 展示 · 成长

03

核心术语

统一产品与研发语言，避免歧义。左侧为规范用词，右侧为应避免的说法。
术语定义避免使用
群空间 Group Space一个微信群对应一个独立的作品空间，成员在此提交和浏览作品。群 / 星圈 / 社区空间
作品 Work用户在群空间中创作的、被系统沉淀的核心实体。本体只有标题、作者、内容/封面、类型、标签、发布时间，跨群一致。内容 / 帖子 / 作品集
投影 Projection作品在某个群空间中的"软链接"。可投影到多个群空间，每个投影独立持有该群的点赞、评论、收藏数；对投影的互动不影响作品本体。软链接 / 投影条目 / 副本
成员 Member加入某个群空间的用户，一个用户可属于多个群空间。用户 / 群友 / 创作者
点赞 Like成员对作品表达认可的动作，按作品聚合计数展示。喜欢 / 赞 / 爱心
评论 Comment成员对作品发表的意见，支持回复与 @用户。留言 / 回复 / 讨论
收藏 Collect成员将作品加入个人收藏的动作。保存 / 书签 / 关注
星轨 Star Trail作者个人的作品档案主页，展示其作品数量、分类分布与最近作品。个人主页 / 作者页 / 档案
时间轴 Timeline按时间展示群体创作历史的视图，支持今日 / 本周 / 本月 / 年度切片。动态流 / 信息流 / 瀑布

05

产品边界

受微信隐私限制，小程序无法

自动读取聊天记录

无法读取微信群历史消息

自动监听群消息

无法感知群内实时动态

自动抓取分享内容

无法自动采集群友分享

因此采用的产品模式

用户主动提交作品 + 微信分享传播模式

07

核心功能需求

七大核心功能模块：群空间、作品发布、信息模型、时间轴、星轨、检索与互动。

7.1 群空间

每个微信群对应一个独立的作品空间。空间内聚合展示本群作品，成员在此提交与浏览，形成群体的内容沉淀。

每群一空间

一个微信群对应一个独立作品空间

最新作品流

空间首页展示群内最新作品

7.2 作品发布

支持五种作品类型，覆盖群内主流创作形式：

文字作品

文章 · 诗歌 · 小说
随笔 · 观点

图片作品

摄影 · 绘画
设计

音视频作品

音乐 · 视频
配音

技术作品

代码 · 开源项目
技术方案

外部作品

网站链接 · 博客
GitHub · 视频链接

7.3 作品信息模型

作品以「作品本体 + 群内投影」的双层结构沉淀：本体跨群唯一，互动计数归属各群投影。

作品本体 Work

id作品唯一标识
标题作品名称
作者创作者（成员）
作品类型文字 / 图片 / 音视频 / 技术 / 外部
标签用于分类检索
内容作品正文或媒体
封面展示用封面图
发布时间创建时间

群内投影 Projection

作品在每个群空间中的"软链接"，独立持有互动数据：

所属群投影所在的群空间
点赞数量本群内的点赞数
评论数量本群内的评论数
收藏数量本群内的收藏数
对投影的互动不影响作品本体，也不影响其他群的投影。同一作品可在多个群空间被独立沉淀。

产品增长机制

10.1 分享驱动增长

以"分享"为核心的增长飞轮：

1
发布作品创作者产出内容
2
生成精美卡片自动生成分享图
3
分享到微信群依托关系链传播
4
群成员浏览新成员进入
5
点赞评论形成互动反馈
6
更多人发布进入下一循环

↻ 循环往复，以内容沉淀带动用户增长

每年为群空间生成一份群星报告，总结群体一年的创作成果，强化归属感与分享欲。
